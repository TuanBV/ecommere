# Git safety

- Không commit trực tiếp vào branch `main` hoặc `master`. Luôn tạo branch riêng cho task, trừ khi người dùng yêu cầu khác rõ ràng.
- Không `git push --force` / `git push -f`. Không rewrite history (`git rebase -i`, amend commit đã push) nếu chưa được yêu cầu rõ ràng.
- Không `git reset --hard`, `git clean -fdx`, `git checkout -- .` khi có thay đổi chưa commit mà chưa xác nhận với người dùng — luôn `git status` trước.
- Trước khi commit: phải xem `git diff`/`git status` để chắc chắn chỉ stage đúng file liên quan đến task, tránh dính file `.env`, `node_modules`, file build (`dist/`, `.next/`).
- Commit message: mô tả rõ "why" thay vì chỉ "what". **Không** thêm các cụm như `code by claude`, `generated by claude`, `AI generated`, `Co-authored-by: Claude` vào commit message trừ khi người dùng yêu cầu rõ ràng.
- Nếu có thay đổi phát sinh ngoài scope task trong lúc làm việc, phải báo cáo rõ trong phần Report, không gộp âm thầm vào commit.
- Chỉ tạo pull request khi được yêu cầu; không tự ý merge PR hoặc đóng issue.
